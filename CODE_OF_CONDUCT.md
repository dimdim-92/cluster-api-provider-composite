# Code of Conduct

The project adopts the behavioral standard of the
[CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).
That choice does not make this a CNCF project or establish a CNCF reporting route.

Report abusive, harassing or otherwise unacceptable behavior privately to a
listed [maintainer](MAINTAINERS.md). If a report concerns one maintainer, approach
another listed maintainer to arrange an appropriate private handling route.
Do not place sensitive reports in public issues.
