# Governance

This is a Numspot-owned project. [Maintainers](MAINTAINERS.md) review changes,
triage issues, coordinate releases and uphold the [Code of Conduct](CODE_OF_CONDUCT.md).

Discuss changes in issues and pull requests. Prefer consensus, practical
explanations and tested behavior. Record lasting implementation decisions in
[docs/design.md](docs/design.md), close to the code and usage they describe.

Maintainers coordinate additions to the maintainer list and changes to release
responsibilities through reviewed pull requests. Release and repository permissions
are managed by the project owners. Security matters use the private reporting
route in [SECURITY.md](SECURITY.md).
